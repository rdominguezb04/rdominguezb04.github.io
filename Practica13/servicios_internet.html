1. Telnet

Telnet es un servicio que permite conectarse a otro ordenador a distancia y utilizar sus comandos.

Se utiliza para controlar equipos de forma remota, aunque no es muy seguro porque los datos se envían sin cifrar.

Volver al índice

2. FTP

FTP significa File Transfer Protocol. Es un servicio que permite enviar y descargar archivos entre ordenadores.

Por ejemplo, se puede utilizar para subir archivos a un servidor o descargar documentos de Internet.

Volver al índice

3. Servidor proxy

Un servidor proxy actúa como intermediario entre nuestro ordenador e Internet.

Puede servir para controlar el acceso a páginas web, mejorar la seguridad o guardar copias de algunas páginas para cargarlas más rápido.

Volver al índice

4. Servidores de correo

Los servidores de correo permiten enviar, recibir y guardar mensajes de correo electrónico.

Utilizan protocolos como SMTP para enviar mensajes e IMAP o POP3 para recibirlos y consultarlos.

Volver al índice

5. Servidor web

Un servidor web es un ordenador o programa que almacena páginas web y las envía al navegador cuando un usuario las solicita.

Utiliza los protocolos HTTP y HTTPS para mostrar páginas web a través de Internet.
